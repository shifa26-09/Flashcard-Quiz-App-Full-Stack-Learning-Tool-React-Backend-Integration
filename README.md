# ⚡ FlashMind — Flashcard Quiz App

A sleek, full-stack flashcard study app with deck management, progress tracking, and smart quiz mode.

## Features
- 📚 Create & manage multiple card decks (with custom colors)
- ✏️ Add, edit, delete flashcards
- 🎯 Quiz mode with flip animation
- 📊 Per-card accuracy tracking (correct / seen)
- 🔀 Randomized card order every quiz session
- 📈 Progress bars per deck
- 💾 SQLite backend (persistent data)

## Setup & Run
```bash
pip install flask
python app.py
```
Open: http://localhost:5001
